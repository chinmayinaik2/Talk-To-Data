# Business glossary (Finance-approved)

| Term | Definition |
|---|---|
| Gross Sales | Invoiced value of all order lines **excluding cancelled orders**. |
| Net Revenue | Invoiced value of **completed** orders only (excludes cancelled and returned). This is the official revenue figure. |
| Cost | Cost of goods for the lines being measured. |
| Margin (official, Finance) | Net Revenue minus the cost of completed lines. |
| Margin % | Margin divided by Net Revenue. |
| Sales-team margin | Gross Sales minus cost of non-cancelled lines. Used informally by the sales team; **not** the official figure. |
| Discount | List price value minus invoiced value, excluding cancelled orders. |
| Discount % | Discount divided by list price value (Discount + invoiced value). |
| Return Rate | Value of returned lines divided by Gross Sales. |
| Order | One transaction (TRX_ID). An order can have several lines. |
| Average Order Value | Net Revenue divided by the number of completed orders. |
| Active Customer | A customer with at least one non-cancelled order in the period. |
| Online order | An order line with the online flag set. |
| Sales rep compensation | Confidential HR data. Not for reporting. |

Fiscal year = calendar year.
